One traceable route

一条研发链路，不再靠群聊拼上下文。

数据版本、标注任务、训练运行、评估门禁、模型版本和部署 Revision 通过不可变引用串联。出现问题时，可以沿着同一条血缘回到原始样本。

01 / INGEST资产进入
02 / LABELCVAT 标注
03 / FREEZE数据集冻结
04 / TRAIN训练运行
05 / EVALUATE质量门禁
06 / RELEASE审批部署
07 / LEARN生产返标
01

数据先被看见，再进入训练。

上传、批量导入、哈希去重、损坏检测和回收站共用一套资产台账。创建数据集版本时，系统同时生成固定划分、Manifest、质量报告和 Dataset Card。

  • 对象存储 Key、内容指纹和业务元数据统一检索
  • 重复内容、损坏图片和缺少标注在冻结前暴露
  • 104/16/8 固定划分可复现，不随训练运行漂移
02

标注工具留在流程里，不另开一座孤岛。

从 VisionAI 创建 CVAT 任务后，项目、数据集版本和任务状态保持关联。标注人员在内嵌工作台完成生产，管理者仍能回到平台查看上下文和下游使用关系。

  • CVAT 原生界面内嵌，不牺牲熟悉的标注操作
  • 支持全屏工作台与外部打开两种模式
  • 任务回调更新状态，减少人工抄录和漏项
03

训练结果不只看一个总分。

训练模板锁定镜像、参数和资源约束；运行归档日志、指标和制品。评估门禁固定数据版本，并把 FP、FN、置信度和 IoU 切片送进 FiftyOne 做样本级复核。

  • Windows RTX 4090 节点通过资源心跳纳管
  • 训练制品摘要与数据、代码和环境血缘绑定
  • 门禁结论和困难样本切片可以复查、复跑
04

模型上线有门槛，出问题也有退路。

只有通过质量门禁并完成职责分离审批的模型，才能获得生产资格。部署保留不可变 Revision；生产低置信度样本经过去重和人工审核后，返回 CVAT 开启下一轮训练。

  • 提交人与审批人分离，审批理由进入审计记录
  • Endpoint、推理 Trace、性能指标和告警统一查看
  • 困难样本按策略采集，不保存完整生产请求体
