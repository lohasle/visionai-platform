02 / Data & annotation

先把输入做对，再谈训练速度。

导入任务、内容指纹、质量规则、标注修订和数据集冻结都在训练前完成，减少训练失败后追查原始图片的时间。

多人并行标注，仍然只需要一个平台账号。

标注员和审核员来自底座用户与项目角色。进入任务时，VisionAI 自动建立个人 CVAT 会话并打开自己的工作分片，原生编辑器与平台上下文自然衔接。

  1. 01批量导入前校验受控目录、对象 Key 与重复策略
  2. 02多名标注员按工作单并行处理，审核角色独立接管
  3. 03个人单点登录、任务状态和数据修订保持关联
03 / Train & evaluate

总分通过之后，继续追问错在哪里。

评估门禁给出是否可发布的结论；FiftyOne 负责把 FP、FN、IoU 和置信度带回具体样本，让指标有解释路径。

训练产物、环境和数据版本一起归档。

Windows RTX 4090 训练节点通过心跳接入，运行结束后归集日志、指标和制品摘要；评估固定引用已冻结的数据集版本。

  1. 01训练模板锁定镜像、参数 Schema 与资源约束
  2. 02运行记录保存代码、数据、环境与制品，并支持整包导出
  3. 03FiftyOne 内嵌筛选 FP/FN，不只展示报表数字

04 / Release & learn

发布不是终点，生产问题要能回到下一版数据。

质量门禁和四眼审批共同决定生产资格；线上低置信度样本经过采样、脱敏、去重和人工审核后返回 CVAT。

版本能追溯，部署能回滚，样本能返标。

模型版本绑定不可变制品、Model Card 和供应链 Manifest；每次部署保留 Revision，生产反馈也保留来源模型与策略。

  1. 01提交人与审批人职责分离，审批理由进入审计
  2. 02Endpoint、Revision、延迟、错误率和告警关联
  3. 03反馈批次去重审核后生成 CVAT 返标任务
05 / Integrated, not replaced

平台负责串联，专业工具继续做专业的事。

VisionAI 不重造缩小版 CVAT 或 FiftyOne。它统一身份、项目上下文、对象引用、运行编排和审计，把成熟工具嵌进可治理流程。
