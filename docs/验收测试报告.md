## 已知非阻断项

- 演示推理 Provider 输出确定性的检测结果，用于验证平台协议、视频解码、监控和反馈链路；生产模型镜像应实现同一 Provider 契约。
- GPU Compose 需要主机预先安装 NVIDIA Container Toolkit；纯 CPU 默认栈无需 GPU。
- 完整栈首次拉取 CVAT/FiftyOne 镜像耗时受网络带宽影响。
