# GitHub Pages 页面规范

本文件覆盖 `design-system/visionai/MASTER.md` 中与 GitHub Pages 落地页相关的规则。

## 信息架构

1. 首屏：一句明确结论、真实工作台主图、公开验收状态和单一主操作。
2. 证据条：COCO128 样本、标注框、评估指标、运行服务等可核对数据。
3. 全链路：从资产、标注、数据集、训练、评估到发布、反馈的连续路径。
4. 三段产品叙事：数据与标注、训练与评估、发布与生产反馈。
5. 集成架构：VisionAI 负责上下文和审计，CVAT/FiftyOne/MinIO 保留原生能力。
6. 证据库：19 张截图按 Data、Build、Release、Ops 分类浏览。
7. 结尾：GitHub 仓库与产品手册。

## 页面气质

- 深色首屏只承担品牌与发布摘要，正文保持高可读浅色。
- 使用严格 12 列网格、大字号标题、细线分隔和小型等宽标签。
- 真实截图占据主要视觉面积；说明文字解释“用户完成了什么”，不罗列抽象功能。
- 品牌蓝只用于主操作、当前筛选与关键线条；绿色只表达健康/通过。

## 验收

- 19 张截图都可在页面到达并打开原图。
- 筛选器使用原生按钮和 `aria-pressed`，筛选后仍保持合理的标题层级与焦点。
- Lightbox 具备 `role="dialog"`、关闭按钮、Escape 路径和焦点回归。
- 375px 无横向滚动；导航、按钮与筛选器均可触摸和键盘操作。
- 页面源文件 UTF-8，无 `????`、替换字符或乱码文本。
