# VisionAI Design System

项目：VisionAI 企业级计算机视觉算法平台

方法：UI/UX Pro Max
视觉方向：Swiss Modernism 2.0 + Operational Editorial

## 产品与受众

- 主要用户：算法工程师、视觉算法负责人、平台工程师和生产运维人员。
- 设计目标：先建立可信度，再解释能力；用真实界面、运行数据和可追溯关系证明产品价值。
- 内容原则：具体、可验证、面向任务。禁用虚构客户、虚假评价、无来源增长数字和空泛 AI 文案。

## 全局令牌

| 角色 | 值 | 用途 |
| --- | --- | --- |
| Ink | `#07111F` | 标题、深色区块、主要文字 |
| Text | `#253248` | 正文 |
| Muted | `#5B6678` | 辅助说明 |
| Surface | `#FFFFFF` | 内容表面 |
| Canvas | `#F3F6FA` | 页面背景 |
| Line | `#D7DEE8` | 边界与分隔 |
| Brand | `#155EEF` | 唯一装饰性强调色与主操作 |
| Success | `#147A5C` | 仅用于健康、完成等语义状态 |
| Warning | `#9A4D0F` | 仅用于风险语义 |

- 不使用渐变、装饰性光晕、玻璃拟态、拟物阴影或高圆角卡片堆叠。
- 圆角以 `0 / 4 / 8px` 为主；阴影只用于截图浮层与模态框。
- 采用 8px 间距体系；桌面内容最大宽度 1280px。

## 字体与数据

- 中文正文：`"PingFang SC", "Microsoft YaHei", system-ui, sans-serif`。
- 拉丁标题与正文：`Arial, "Helvetica Neue", sans-serif`，不依赖远程字体。
- 状态、步骤、版本号和指标：`ui-monospace, "Cascadia Code", Consolas, monospace`。
- 标题紧凑但正文保持 1.6 行高；长段落限制在 68 个中文字符等效宽度内。
- 数字使用 `font-variant-numeric: tabular-nums`。

## 组件规则

- 按钮最小高度 44px，主按钮每个视区最多一个。
- 所有链接、按钮和截图预览具备清晰的 hover、pressed 与 `:focus-visible` 状态。
- 截图必须来自真实验收环境；声明宽高，首屏图片优先加载，其余懒加载。
- 内容区优先使用网格、分隔线和留白形成层级，避免“每段一个卡片”。
- Lightbox 支持键盘打开、Escape 关闭、焦点回归和可读说明。

## 响应式与可访问性

- 验收宽度：375、768、1024、1440px。
- 移动端先呈现核心价值和真实产品图；所有多列网格顺序重排为单列。
- 不允许水平滚动、被粘性导航遮挡的锚点或小于 44px 的点击目标。
- 页面包含 skip link、连续标题层级、描述性替代文本和高对比焦点环。
- 尊重 `prefers-reduced-motion`，不把可读内容依赖于动画或 JavaScript。

## 禁止模式

- Newsletter、定价页或通用 SaaS 模板结构。
- 粉紫渐变、发光边框、HUD 科幻装饰、假终端和无意义网格背景。
- emoji 结构图标、随机图标风格、弹跳动画和 hover 布局位移。
- “赋能”“重塑未来”“智能驱动”等不能映射到产品行为的口号。
